# Android Mobile Design & Material Design 3

Esta skill reúne os padrões do **Material Design 3 (Material You)** e princípios de design móvel para construir aplicações fluidas, acessíveis e adaptativas.

## Quando Usar

- Design de interfaces móveis seguindo diretrizes do Material Design 3 e WCAG AAA
- Implementação de layouts adaptativos (telefones e tablets)
- Paletas de cores tonais com alto contraste (Dynamic Color e Dark Mode)
- Áreas de toque seguras (mínimo de 48dp / 56dp para público sênior)
- Transposição para React Native Reusables (o shadcn/ui do React Native)

## Princípios Chave do Material 3 no everMind

1. **Acessibilidade Tonal:** Uso de paletas tonais para garantir contraste de texto $\ge 7:1$.
2. **Touch Targets:** Alvos de toque de no mínimo 48dp (botões principais em 54dp ou 64dp).
3. **Cards & Elevações Suaves:** Separação clara de conteúdo sem sobrecarga cognitiva.
4. **Componentes shadcn/RN:** Integração com **React Native Reusables** (`src/components/ui/`).
