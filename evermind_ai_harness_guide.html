O Que É um AI-Driven Harness 100% Agnóstico?

Nossa arquitetura de Harness não depende do OpenAI Codex ou de ferramentas proprietárias. Ela é um padrão universal de engenharia baseado em especificações Markdown canônicas (CONTEXT.md, docs/DECISIONS.md e .agents/harnesses/*.md) que orienta qualquer agente de IA (Antigravity, Claude Code, Cursor, Gemini, Codex, etc.) de forma determinística e empática.

⚠️ Riscos Sem o Harness no everMind

O que agentes não restringidos costumam errar em apps de saúde e longevidade:

  • Copywriting Punitivo: Exibir "Você perdeu seu streak de 6 dias", gerando ansiedade e abandono em usuários mais velhos.
  • Falta de Acessibilidade: Adicionar textos pequenos, baixo contraste ou elementos clicáveis minúsculos.
  • Sobrecarga Cognitiva: Criar mini-jogos matemáticos punitivos com cronômetro regressivo agressivo.
  • Acoplamento de Código: Misturar lógica de sensores móveis, persistência e UI em um arquivo espaguete.
✅ Benefícios com o Harness Agnóstico

Como os guard rails canônicos blindam o desenvolvimento no React Native:

  • Ordem de Leitura Estrita: Todo agente lê docs/DECISIONS.md antes de alterar código ou criar componentes.
  • Política Anti-Culpa Obrigatória: Mensagens de fallback gentil ("🌱 Tudo bem! Hoje é um novo dia") validadas em testes.
  • Deep Modules & Seams Limpos: Lógica de gamificação e mini-jogos isoladas por interfaces TypeScript testáveis via TDD.
  • Portabilidade Total: Funciona perfeitamente em qualquer editor, agente de linha de comando ou IDE.
🌿 Os 4 Pilares da Longevidade no everMind
O aplicativo organiza a rotina em torno de 4 eixos essenciais de saúde integrada: 1. Mente (Estimulação cognitiva, memória, vocabulário, música), 2. Movimento (Caminhada leve de 10 min, quintal/casa), 3. Autocuidado (Hidratação, fruta/vegetal, higiene do sono), e 4. Conexão (Afeto, telefonemas e conversas familiares).

Arquitetura Mobile (React Native + TypeScript)

Estrutura técnica otimizada para performance mobile, operação Offline-First e acessibilidade sênior máxima.

📱 Core Mobile Stack

React Native + TypeScript (Expo SDK):

  • Navegação: @react-navigation/native (Stack + Bottom Tabs com ícones grandes).
  • Gerenciamento de Estado: Zustand (leve, performático e desacoplado da UI).
  • Animações Suaves: react-native-reanimated para evolução do Cérebro Virtual.
💾 Offline-First Storage

Persistência Local Confiável:

  • Motor: react-native-mmkv ou AsyncStorage para acesso ultra-rápido síncrono.
  • Resiliência: Todos os 3 desafios diários e o estado de streaks funcionam sem internet.
  • Sincronização em background transparente quando houver conectividade.
🔊 Áudio, Haptics & Acessibilidade

Feedback Sensorial Agradável:

  • Áudio: expo-av para mini-jogos musicais e sons sutis de vitória.
  • Haptics: expo-haptics para confirmações táteis de conclusão.
  • WCAG AAA: Suporte a Dynamic Type (fontes escaláveis) e áreas de toque ≥ 48x48dp.
📂 Estrutura de Pastas de Código (`src/`)
src/ é organizado em Deep Modules modulares:

• src/modules/brain/ (Mini-jogos de memória, sequência, palavras, atenção, música)
• src/modules/gamification/ (Máquina de estados do Cérebro Baby➔Mega, Streaks gentis, Conquistas)
• src/modules/habits/ (Gerenciador dos 4 pilares: Mente, Movimento, Cuidado, Conexão)
• src/screens/ (As 7 telas React Native focadas puramente em apresentação e composição)
• src/ui/ (Design System acessível: botões grandes, cards contrastantes, tipografia sênior)
